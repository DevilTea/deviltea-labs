# Packages

DevilTea Labs packages are independently versioned and published to npm. Their
README files are the canonical documentation and are rendered here directly.

- [`@deviltea/eslint-config`](./eslint-config) — opinionated ESLint flat config
  for JavaScript, TypeScript, and Vue.
- [`@deviltea/tsconfig`](./tsconfig) — strict TypeScript presets for browser,
  Node.js, bundler, and tooling projects.
- [`@deviltea/vue-router-middleware`](./vue-router-middleware) — composable
  middleware for Vue Router guards.
- [`vue-temp-var`](./vue-temp-var) — temporary template variables with Vue type
  inference.
- [`@deviltea/tiny-state-machine`](./tiny-state-machine) — a small,
  type-safe state-machine core.
- [`@deviltea/tiny-state-machine-vue`](./tiny-state-machine-vue) — Vue adapter
  for tiny-state-machine.
- [`@deviltea/ef`](./ef) — file-based, Git-native engineering knowledge system
  and CLI.
